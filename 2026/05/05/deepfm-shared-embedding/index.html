论文精读｜DeepFM：FM 和 DNN 为什么共享 embedding

发表于 2026-05-05 分类于 推荐系统
结构图里最有用的不是两条支路，而是共同的输入表示。

回顾笔记 · 按学习路线归档，非当日发布。

DeepFM 的两条支路不是先训练一个 FM，再把它的打分喂给神经网络。FM 负责表达低阶交互，DNN 从多个 field 的向量拼接中学习更复杂的组合，二者在输出端合并。关键是输入的特征 embedding 共享，梯度从两边回来。

怎么拆开做对照

只跑完整模型看不到是谁贡献了收益。可以固定 embedding 维度和训练数据，做线性、FM、DNN、DeepFM 四组。如果还想知道共享本身有没有用，再加一个不共享版，同时记下参数量变化。二阶交互能算出来，不代表深支路真的学到可迁移的高阶规律。

工程上先把 field 定义写清楚。一条输入若把“商品类别缺失”和“未登录用户”映射成同一个 ID，结构再好也解决不了语义混用。

参考

  • Guo 等，DeepFM: A Factorization-Machine based Neural Network for CTR Prediction（2017）
