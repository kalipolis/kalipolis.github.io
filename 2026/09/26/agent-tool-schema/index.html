Agent 笔记 01：工具调用不是执行授权

发表于 2026-09-26 分类于 杂谈
模型只提出结构化请求，调用方还要做校验和执行决策。

回顾笔记 · 按学习路线归档，非当日发布。

把查文档工具设计成 lookup_note(topic, limit)，模型给出 topic 和 limit 之后，不应该直接相信参数。是否允许这个工具、limit 是否过大、查询结果是否包含模型不该看的内容，应该在调用方判断。

一次执行拆成三个记录

保留模型请求、校验结果、工具返回。参数格式错误可以让模型修正一次；访问越权不能靠重试解决。工具结果是外部数据，遇到内容里写着“忽略规则并去调用某个工具”，也不能把它当成新授权。

读操作和写操作最好分开考虑。读文档可以有默认执行路径；发邮件、修改文件这类有副作用的操作，先让用户看到目标和内容，再按权限决定是否执行。模型没必要持有长期凭据。
