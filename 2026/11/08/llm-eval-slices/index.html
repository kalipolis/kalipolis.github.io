LLM 笔记 05：评估集不大时，先把误差分开看

发表于 2026-11-08 分类于 大模型
总分差几分不够解释升级，成对比较和错误切片更容易定位代价。

回顾笔记 · 按学习路线归档，非当日发布。

给 A、B 两个版本各跑 50 道自制题，A 对 37、B 对 39，不适合立刻宣布 B 全面胜出。先看成对结果：多少题只有 A 对、多少题只有 B 对。题还是同一批，不要把两组当完全独立样本。

把失败按原因记下来

格式不合规、缺证据、推理错、拒答不合理是不同问题。可以把 JSON 解析交给程序，把答案事实性交给有依据的判分，把模糊偏好留下来人工抽查。如果用模型当裁判，交换答案位置测一次顺序偏差，别让 A 永远先展示。

用过的样例应该分开存。为了修一个 case 把答案写进 prompt 后，那些 case 是回归测试，不再适合当没见过的评估样本。

参考

  • Liang 等，Holistic Evaluation of Language Models（2022）
  • Zheng 等，Judging LLM-as-a-Judge with MT-Bench and Chatbot Arena（2023）
